- `qa/` — буквальные границы выполненных проверок.

## Запуск
Node 24, Remotion 4.0.454, Chromium, FFmpeg; для микса — Python и numpy.

```sh
cd film
npm install
npm run studio
```

Основная композиция `EP3-REDO-TEST` — без звука для воспроизводимого видео. Композиция `EP3-REDO-TEST-AUDIO` — для просмотра с финальным тестовым звуком в Studio.

```sh
node render-redo.mjs --stills
node render-redo.mjs --out out/redo/redo-preview-silent.mp4 --concurrency 2
node export-preview.mjs
```

При необходимости `CHROMIUM_PATH=/path/to/chromium`. Микс запускается `python ../build/mix-preview.py`. Голосовая дорожка обрезается только после целого последнего слова, до первой фразы следующей секции. Озвучку не ускорять.

## Важные ограничения
Прозрачная интерполяция двух сильно разных упражнительных поз давала двойную голову. В тесте заменена на монтажную смену целых зарегистрированных поз по слову: это не настоящее непрерывное движение тела и не optical-flow/morphing. Профильный прогресс тела в полном выпуске требует другого, проверенного решения.

Нельзя использовать декоративные рамки, винтажные весы, полароиды и псевдо-анатомию из старых библиотек только потому, что они там есть. Новые рисунки и их правки — только A6API, с проверкой цены/route и малым ключевым тестом. Секретов в этой папке нет.
