# Rendo — EP3: Why Your Belly Still Looks the Same

Текущая кандидатная сборка, не пользовательское одобрение. Английский Jonathan, 7:48, 1920×1080, 30 fps.

## Файлы
- `rendo-ep3-belly.mp4` — итоговый ролик, предоставляется отдельно от архива исходников.
- `film/src/Episode3.tsx` — редактируемые композиции и анимация.
- `film/src/timeline.json` — 70 сцен, тайминги и текст.
- `film/public/art` — используемые изображения, включая зарегистрированные пары поз.
- `film/public/audio` — подготовленная речь, отдельные voice/music/SFX stems и master.
- `voice` — полный сценарий, три исходных take, word marks и alignment.
- `raw` — восстановленные оригиналы новых изображений и новая музыка.
- `qa` — проверки и ограничения; `references.md` — научные источники.

## Рендер без платных API
Node 20+ и FFmpeg. В `film` выполнить `npm install`, затем `npm run export`. Установить Chromium и при необходимости `CHROMIUM_PATH=/путь/к/chromium`. `npm run studio` открывает визуальные композиции; звук уже сведен в master. `npm run stills` обновляет ключевой кадр каждой сцены. Видео рендерится отдельно, затем экспорт присоединяет master.

Исходники самодостаточны для рендера: доступ к генераторам и секреты не нужны. Старые scripts EP1 удалены из npm-команд.

## Восстановление
Проект восстановлен из истории после потери прежнего рабочего окружения. Оригинальные три take Jonathan извлечены без новой генерации и без изменения скорости. Восстановлены восемь новых рисунков; белковая тарелка взята из ранее утвержденного EP1. Утерянный музыкальный файл заменен одной новой генерацией. Не все исходные prompts/request receipts восстановлены; не выдавать их отсутствие за полную историю генераций. Старый recovery manifest с pending voice/music заменен актуальным.

Финальный MP4 использует точечные повторные рендеры четырех диапазонов: 93–101, 257–263, 334–344 и 405–416 секунд. Текущий код уже содержит эти исправления, новый полный рендер не требует вставок. Голос не сдвинут.
