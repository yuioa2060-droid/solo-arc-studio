# Рисунки, вырезание и регистрация

## Стиль этого направления

По умолчанию: чёрный/почти чёрный фон, крупные чистые 2D-вырезки с тонким чёрным контуром, сдержанное анатомическое штрихование, ограниченная палитра. Цвет акцента показывает область/идею, а не украшает весь экран. Это отдельный канал: не переносить автоматически bald/Imagine-мастер, anime-фоны или финансовые карточки.

Для оригинальных роликов сначала определить собственную узнаваемую фигуру и её reference sheet. Исследованный персонаж объясняет постановку, но не обязывает все будущие каналы использовать чужую идентичность. Сохранить стабильные пропорции, одежду/акценты и выразительные целые жесты.

## Запрос внешнему API

Порядок блока запроса:

1. **Что создаётся:** один полный рисунок/пара поз, размер 16:9 или явно выбранный холст, прозрачный фон.
2. **Роли референсов:** identity, drawing style, pose/action; отдельно запретить копирование посторонней композиции/UI из pose-референса.
3. **Видимая механика:** ракурс, направление тела, опоры, движение, хват, предмет, состояние до/после.
4. **Что остаётся неподвижным:** таз, стопы, колени, станок — перечислить конкретно для упражнения.
5. **Кадрирование:** вся фигура/предмет/пальцы внутри безопасных полей; без срезанных головы, стоп и диска.
6. **Рисовка:** собственный мастер + материал/контур/штрих/ограниченные акценты; no scenery/UI/words/watermark.
7. **Фон:** native alpha preferred; если провайдер не поддерживает — чистый #FF00FF без отражения key-цвета на фигуре. Не просить зелёный фон для зелёных мышц.

Полнота означает точную механику, а не длинный список бессмысленных деталей. Не заставлять персонажа показывать экран зрителю; телефон/лист смотрит к пользующемуся им человеку, предметную информацию можно показать отдельным кропом.

## Внешний API и цена

В этом проекте использовать имеющийся `src/lib/gen-image.ts`, ключи только из окружения. Не печатать секреты и не вшивать их в скилл. Исключение по прямой просьбе пользователя2026-10-06: приватный пакет передачи Claude содержит отдельный A6API-ключ, но остальные секреты не экспортируются. Текущий маршрут не угадывать из старого vendor ID.

Сначала сравнить совместимые предложения, включая поддержку references, размер и ограничения. Пользователь 2026-10-05 разрешил при сбое попробовать другого по той же/ближайшей следующей цене. Не тратить много попыток на один зависающий маршрут: одна контролируемая попытка, затем следующий явно выбранный поставщик. Не включать широкий непредсказуемый fallback. После результата остановить перебор.

Журнал должен содержать start/end, channel, model, expected price, result и actual billed cost. Проверять `/api/log/token`: quota, quantity и `market_price_micros`. HTTP-timeout не доказывает нулевую стоимость; учитывать и ответы, потерянные после списания. Не считать финальные картинки числом платных запросов. Не выставлять «minimum price passed», когда оплаченных строк вообще нет.

## Альфа и кайма

- Прочитать реальные размеры/каналы raw PNG. API иногда возвращает native alpha и размер, отличный от запрошенного.
- На raw alpha не удалять «чёрный фон» по цвету: это уничтожит линии.
- Для pure-magenta удалять только доказанный key; порог зависит от результата. В одной проверенной паре использовались g<35, min(r,b)-g>25, abs(r-b)<40. Это отправная точка, не универсальный пресет.
- Despill ограничить краем и сохранить фиолетовую/цветную одежду. Полная десатурация фигуры недопустима.
- Проверить весь PNG и увеличенный край на чёрном фоне: волосы, руки, пальцы, колени, стопы. Непрозрачная цветная кайма тоже возможна, одного контроля полупрозрачных пикселей мало.

## Пара поз

1. Выбрать одинаковый холст и перспективу; определить опорную систему.
2. Разметить таз, колени, пятки/носки и при необходимости хват/плечи для обеих поз.
3. Совместить только одним равномерным масштабом и переносом. Сохранить целые фигуры; не подклеивать независимые части.
4. Сравнить контуры неподвижных зон, не только две точки. Остаток 7 px на ориентирах не доказывает идентичность всех ног.
5. Проверить down/up/down и 25/50/75% crossfade на конечном масштабе.
6. Новая пара повторяется во всех соответствующих демонстрациях, финальной карточке и её пикселизированном тизере.

Изменённые PNG сохранять независимым новым именем; старые public-файлы могут быть hardlinks на готовые версии.

## Направляющие

Для мышц и обучающих указателей сначала прочитать [anatomy-and-instruction.md](anatomy-and-instruction.md). До работы с координатами определить структуру, функцию и смысл в озвучке. Произвольное пятно внутри тела не является верной анатомической разметкой.

Измерять на уже принятом PNG. Нормализованные координаты `[u,v]` связаны с полным холстом, включая прозрачные поля. Локальный путь/круг поместить в тот же wrapper, что изображение. Объясняющую подпись снаружи связывать через `geometry(...).point([u,v])`. Когда поза меняет соответствующую область, проверить путь на обеих позах или дать отдельные координаты по состояниям.
