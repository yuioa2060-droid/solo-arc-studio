# Библиотека 17 приёмов

Подробные исторические параметры и названия в `production-pattern-catalog.json`. Код базовой геометрии/прорисовки/SVG в `assets/runtime/`. Связать каждый приём с конкретным смыслом собственной речи.

| № / приём | Зачем и когда | Постановка и ограничения |
|---|---|---|
| 1. Первое знакомство → предмет → действие | Сначала зритель понимает, что показывают, потом чем это делают | Целая фигура и временное название. Название отдельно от времени входа тела. Предметы отдельной вставкой. Затем основной цикл по словам. Не закрывать первое знакомство чёрной карточкой автоматически. |
| 2. Вставка про руки/ошибку | Объяснение касается детали, плохо видимой на общем плане | Самостоятельный крупный рисунок, затем возврат. Не удерживать правильное упражнение, когда голос объясняет ошибочный хват. |
| 3. Ведущий + постепенное обещание | Герой лично формулирует результат | Сначала фигура, потом локальный цвет, затем номера и исходящие лидеры. Крупная фигура важнее постоянного заголовка. |
| 4. Чёрная речевая карточка | Сделать одну мысль слышимой и дать визуальный контраст | Короткий **точный собственный** фрагмент речи, тайминг по словам. Маленький текущий номер главы может остаться. Не дублировать весь рассказ субтитрами в центре. |
| 5. Две зарегистрированные целые позы | Показывать упражнение без генерации видео | Одинаковый холст, стационарные опорные точки. Короткое смешивание; оба изображения целиком. Не превращать сгибание в вращение прямоугольного торса. |
| 6. Установившееся начальное положение | Зритель сначала понимает исходную позу | Отдельная фаза: вход → полная видимость → удержание → изменение. Если времени мало, сделать неподвижное проявление, а не дёрганый быстрый въезд. |
| 7. Сравнение темпа | Объяснить различие контроля и торопливости | Разные собственные примеры/паузы/переходы поз. Не ускорять закадровый голос, чтобы изобразить плохое выполнение. Не копировать порядок упражнений автоматически. |
| 8. Номер главы переживает акцент | Сохранить контекст при исчезновении рисунков | Небольшой угловой знак — отдельный persistent layer. Центральный номер и угловой номер имеют разные размеры и Y. |
| 9. Установленная шкала | Показать состояние, а не изменение | Если значение уже существует, шкала заполнена при появлении. Анимация от нуля означала бы иную мысль. Единицы и доля проверяются по речи. |
| 10. Скрытый план → раскрытие | Создать ожидание и дать практический финал | Пикселизированные растры тех же текущих карточек; финал читаемый. Не старые неподходящие картинки. |
| 11. Тизер строками с удержанием | Обещание раскрывается не одновременно | Индивидуальные revealAt и мягкий вход. После последней строки остаётся установившееся окно; проверить нижнюю строку во время входа. |
| 12. Анатомический лидер наружу | Связать подпись с конкретной зоной | Локальная точка тела → подпись. Прорисовывать геометрию, не всю линию opacity. Белая линия + тёмный контур; label может входить раньше линии. |
| 13. Стрелка внутри фигуры | Научить направлению/траектории | Нормализованные собственные точки, общий wrapper. Перемещение/масштаб фигуры не отрывает стрелку. Не переносить координаты другой картинки. |
| 14. Неподвижные числа на цикле | Повторы/этапы становятся ясны | Рисованная двухстрелочная форма вращается медленно, текст не вращается. Под текстом тёмный контур; диапазон и единицы дословно соответствуют собственной речи. |
| 15. Ведущий входит сбоку | Возвращение ведущего меняет композицию | Одна общая геометрия, маленькая инерция; не заменить требуемое направление подъёмом снизу. |
| 16. План → режим/частота | После «что делать» объяснить «как часто» | Строки отдельно, затем самостоятельный смысловой переход к времени/частоте. Не оставлять всё на экране одновременно. Числа параметризовать. |
| 17. Реальный календарь | Показать длительность/регулярность | Реальные 28/29/30/31 дат, остаточные клетки пустые. Не выдавать 35 мест сетки за 35 дней месяца. |

## Инструменты вариации

- Один механизм можно показать разным образом: локальная стрелка, большая предметная вставка, сопоставление двух поз, медленная смена обозначения. Выбирать самое ясное.
- Не выдумывать упражнению направляющую ради наличия эффекта. Если понятнее зелёный круг у опоры, использовать круг.
- При крупном кропе объяснить, что он выделяет; проверить реальную альфу, чтобы не остались одни ноги или половина туловища.
- Количество объектов не равно динамике. Динамика возникает из порядка мысли, смены фокуса и ощутимого установившегося состояния.
- В новом эпизоде использовать собственные названия, рисунки и число строк. У четырёхстрочного исследованного плана нет статуса обязательного формата.

## Причины известных ошибок

1. Незаданный `badgeKey` совпал с чужим объектом без key: линия стала прозрачной. Исправление — lookup только по явно заданной связи. SVG-маска не была доказанной причиной.
2. Готовая линия появилась целиком: не видно обучения. Исправление — линейная интерполяция/квадратичное подразделение самой кривой в `progressivePath`.
3. Обводка тела при долгом pose dissolve двоилась. Проверять 25/50/75% смеси, уменьшать смесь или улучшать регистрацию всей пары.
4. «Lowered» вернул всё ещё поднятые плечи. Запрос должен описывать контакт затылка/лопаток/таза, направление лица и неподвижные колени/стопы.
5. Спокойный масштаб заменили маленькой учебной сеткой. Проверка по голове, плечам, поясу и видимой нижней части, а не только по ширине PNG.
6. Поиск числа `12` изменил и диапазон `8–12`. Сравнивать всю семантику чисел и единиц, не подстроку.
