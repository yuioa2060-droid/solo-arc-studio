## Что осталось сделать

1. Сохранить постановку принятой минуты, применив две новые правки: **красные рваные brush/ink-зачёркивания** и **редкие понятные стрелки направления упражнения**. В поставленном тесте эти новые пожелания ещё не выполнены.
2. Поставить остальной выпуск в том же качестве и ритме: разные масштабы, предметные действия, сравнения, текстовые паузы, упражнения и практический план. Не вставлять остаток старой 70-сценной версии как есть и не размножать одну сетку.
3. Собрать полный микс. В тесте после `loss.` голос заглушён с 58.97 сек; следующий `In` в полном WAV начинается в **59.11**. При продолжении использовать полный голос и перестроить этот стык — не приставлять остаток после тестовой чёрной концовки 60.3 сек с обрезанной фразой.
4. Проверить кадры, границы PNG, загрузку Jost, смены поз, синхронизацию, весь финальный MP4 и его звук. Передать полный MP4 и новый самодостаточный ZIP с кодом/ассетами/звуком/правилами/QA.

Не нужны новый сценарий с нуля, новый голос или повторная массовая генерация уже имеющихся картинок. Полный английский сценарий совпадает в обоих архивах, а полный `voice-full.wav` совпадает по SHA-256 с исходным `voice.wav` первой сборки. Для новых сцен использовать доступный art первой сборки, сохраняя принятые варианты из новой минуты.

## Запуск из корня репозитория

```sh
git lfs install --local
git lfs pull --include="episodes/ep3-belly-fat/**,episodes/ep2-hunger/final/**,assets/channel/**" --exclude=""
npm ci
npm run browser:ensure
npm run check:ep3
npm run studio:ep3
```

Проверочный переносимый рендер текущей минуты:

```sh
npm run render:ep3-sample -- --out outputs/ep3-rebuilt-sample.mp4
```

Это **воспроизведение принятого теста**, не команда завершения 7:48. Для нового полного монтажа Claude должен добавить сцены и полную композицию/микс, после чего обновить реальные команды/длительность в документации. Не увеличивать одну `durationInFrames` и не растягивать минуту до полного хронометража.

Общий lockfile закрепляет Remotion 4.0.454; вложенный `npm install` не требуется. Нужны Node 22.4+ (желательно 24), Python 3.11+, FFmpeg/FFprobe, Chromium. Поддерживаются `REMOTION_BROWSER_EXECUTABLE` / `CHROMIUM_PATH`, `SOLO_ARC_FFMPEG` и `SOLO_ARC_FFPROBE`. Проверки и повторный рендер используют имеющиеся материалы, без платных API.

## API и сохранность

Новые изображения — только A6API. [Текущий статус](../../context/API_STATUS_20261015_RU.md): проверена Nano Banana 2.1; маршруты GPT Image 2.5 при последней настройке не заработали. Это датированное состояние, а не вечный запрет модели. Ключи — только окружение/игнорируемый `.env` или зашифрованные Secrets, не содержимое clone или диалога.

Не удалять EP1/EP2 и не перезаписывать принятый минутный MP4. ZIP-контейнеры не продублированы: все их файлы уже раскрыты в дереве и учтены в provenance. Наличие старой отклонённой сборки здесь — прямое исключение по новому запросу владельца от 15 октября; другие архивные версии автоматически не возвращать.
