# SOLO ARC EP1 v11

Текущий готовый ролик и его редактируемый Remotion-проект. В конце убраны шесть лишних whoosh; два осмысленных входа плана/холодильника тише. Начало/середина SFX и голос сохранены. Присланная музыка слышнее, глобальный шум/зерно по краям удалены. **11.10.2026** весь MP4 пересобран с исправлением тонких прямоугольных светлых границ PNG; исходные рисунки и монтажные тайминги сохранены.

`solo-arc-ep1-v11.mp4`: 1920×1080, 30 fps, 9743 кадра, около 324.767 s, H.264 + AAC stereo. SHA-256: `5a26eb8921737104355600f02e6750361eb18f8051712e6c99643559ff3aa552`.

## Рабочие материалы

- `film/`: текущий код, PNG, Jost, master, музыка пользователя и используемые SFX.
- `voice/`: текущий английский текст, raw MP3, подготовленный голос и word marks.
- `raw/`, `prompts/`, `ref/`: исходные рисунки, запросы и стилистический референс текущего проекта.
- `film/out/v11/`: voice/SFX/music stems, актуальные SFX events, отчёты и выбранные проверочные кадры.

Старые видео, архивные сборки и README предыдущих версий исключены. Внутренние имена Film6/tl6/Ep6 остались в текущем коде; применять действующие правила канала.

## Запуск

Из корня репозитория: `npm ci`, `npm run doctor`, `npm run studio`, `npm run render:preview` или `npm run render:ep1`. В независимой копии через helper можно запустить команды из `film/` после `npm ci`.

Мастер `film/public/audio/master-v11.wav` уже нормализован и включает принятый голосовой offset. Не повторять сдвиг и loudnorm при mux. `render-portable.mjs` и `render-resume.mjs` используют его напрямую.

Для отдельной пересборки микса из текущих stems: `python film/mix-v11.py --ffmpeg <absolute-ffmpeg-path>`. Результат появится в `film/out/rebuild-v11/`; готовый мастер и MP4 не перезаписываются. Изменение SFX сначала требует изменения соответствующего stem; events описывают существующий принятый звук. Новое видео требует нового голоса, marks, сцен и аудио.

## Фактические проверки текущего финала

Полное FFmpeg-декодирование обоих потоков исправленного MP4 прошло без ошибок. Все 15225 AAC-пакетов и их timestamps побитно совпадают с принятым звуком до исправления краёв. Поэтому измерения микса сохраняются: WAV −14.10 LUFS / −1.49 dBTP; AAC −14.15 LUFS / −1.16 dBTP, 48 kHz stereo. Последний кадр чёрный. В декодированном кадре 5 s фон справа от героя и под весами равен #060606, без прежних полос. Проверочные кадры и контактный лист обновлены из текущего MP4; детали — [edge-fix-report.json](film/out/v11/edge-fix-report.json). PNG mappings/headers, duration и версии Remotion проверены; голос и ранние SFX ранее сверены по PCM.

Просмотрены выбранные кадры и контактный лист, выполнены измерения и decode. Непрерывный художественный просмотр и полноценное прослушивание всего ролика в этой среде не заявляются. Отчёты в `film/out/v11/` описывают сделанные проверки, а не новое творческое одобрение.
