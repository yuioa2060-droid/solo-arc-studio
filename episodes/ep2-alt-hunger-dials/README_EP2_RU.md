# EP2 · «Почему хочется есть при дефиците и как приглушить голод»

> **Статус папки.** Это альтернативный черновик EP2, собранный ассистентом, а не финальный EP2 владельца. Финал EP2 (`How I Lost Fat Without Starving Myself`) лежит в `episodes/ep2-hunger/`. Эта папка называлась `episodes/ep2-hunger/`, пока в `main` не появился финал; файлы перенесены сюда без изменений. Пути `episodes/ep2-hunger/…` внутри `raw/*.audit.json` и `voice/full.request.json` — исторические записи запросов, их нужно читать как этот каталог.

Продолжение темы из финала EP1 («если от еды меньше всегда голодно — исправим в следующем видео»). Рабочее название ролика: **Why You're Always Hungry on a Diet (And How to Turn It Down)**; название и описание не утверждены, публикация не выполнялась ([черновик](UPLOAD_DRAFT_EP2_RU.md)).

**Идея.** Голод — это тревога, которую нельзя выключить, но можно приглушить. Четыре «ручки»: **белок → объём → настоящая еда → вечер**. Каждая ручка опирается на исследование (в тексте названо число участников и условие), в конце — один день питания на карточках и честное предупреждение. Финал: «сегодня вечером решите завтрашний завтрак — это ручка номер один; остальное подождёт».

## Как собрано (воспроизводимо)

```sh
# голос: один take, dry-run по умолчанию; ключи только из окружения
node --env-file=<credentials.env> scripts/voice.mjs --script episodes/ep2-alt-hunger-dials/voice/full.txt --out episodes/ep2-alt-hunger-dials/voice/full --send
cd episodes/ep2-alt-hunger-dials/voice && python tighten.py      # паузы + ритуалы глав, новые marks
cd ../film && python mktl.py && python mix-ep2.py       # tl.ts и мастер (−14 LUFS); --music --tp -2.0 для варианта с музыкой
node doctor.mjs
REMOTION_BROWSER_EXECUTABLE=/usr/local/bin/google-chrome node render-portable.mjs --silent --out out/render/ep2-silent.mp4
ffmpeg -i out/render/ep2-silent.mp4 -i public/audio/master-ep2.wav -map 0:v:0 -map 1:a:0 -c:v copy -af apad=whole_dur=308.1 -c:a aac -b:a 256k -t 308.1 -movflags +faststart ../solo-arc-ep2-hunger.mp4
python qa-ep2.py ../solo-arc-ep2-hunger.mp4 --expected-frames 9243
```

Картинки: `tools/a6gen.mjs <имя> --hero|--obj [--ref файл] --send` (один платный запрос, расход считается по счётчику аккаунта), `tools/prep_alpha.py` (raw на чёрном → RGBA без вырезания внутренних чёрных линий), `tools/sheet.py` и `tools/stills_sheet.py` — контактные листы.

## Фактически выполненные проверки

- **Сценарий:** 11 первичных источников открыты в PubMed/PMC, числа сверены с абстрактом/полным текстом (`notes/science-notes-ru.md`). Одну ошибку нашли и исправили до рендера: в первом take «в двадцати четырёх экспериментах» относилось ко всему обзору Robinson 2013, а не к отвлечению при еде; фраза переписана, голос записан заново (первый take заменён).
- **Рисунки:** 11 новых картинок A6API просмотрены на тёмном фоне #060606 (лицо, волосы и шорты героя, штрих, цвета, края alpha). Тест `h-hungry` и `o-apple` делался отдельно до серии.
- **Монтаж:** несколько проходов по кадрам Remotion (около 160 stills по всем главам и стыкам), исправлены наложения и пустые окна; из финального MP4 извлечено и просмотрено 35 кадров по всем главам; `doctor.mjs` без ошибок.
- **Файл:** ffprobe — 1920×1080, 30 fps, **9243 кадра = ожидаемым**, A/V длительность совпадает, полный FFmpeg-decode обоих потоков без ошибок; последний кадр чёрный (яркость 0); фон в 9 проверенных кадрах ровно #060606; в 9 кадрах нет одиночных прямых светлых линий (проверка по строкам/столбцам). Формат yuvj420p/pc-range такой же, как у принятого EP1 v11.
- **Звук:** основной MP4 после AAC — **−14.0 LUFS, true peak −1.4 dBTP**, LRA 3.3; вариант с музыкой — −14.1 LUFS, −1.7 dBTP (первая версия давала −0.9 dBTP, микс пересведён с потолком −2.0). 91 SFX-событие, редкие и тихие (потолки по типам повторяют баланс EP1); whoosh не стоит на каждую смену картинки, щелчки идут за поворотом ручки.

## Чего не было

- **Непрерывного просмотра и прослушивания** целиком в этой среде не делалось: смотрел кадры и числа, слушать не мог. Паузы, интонацию, тембр, возможные неудачные произношения и ритм SFX нужно оценить на слух владельцу. Измерения и decode не равны творческому одобрению.
- **Баланс A6API на время исчерпался:** `o-alarm` ушёл в 504 (списано 780 единиц, рисунка нет), `o-fish` получил 403 «недостаточно квоты» дважды. Позднее пробный `o-beans` прошёл, но монтаж к тому времени был отрендерен, поэтому недостающие `o-alarm`, `o-fish`, `h-glass`, `h-turn` не делались (промпты готовы в `prompts/`). Итого потрачено ≈ $0.021 на 12 удачных запросов и один таймаут (`notes/a6api-log-ru.md`). Монтаж обходится без них: будильник заменён ручкой-дайлом и волнами тревоги кодом, воду показывает `o-glass`, остальные герои — принятые позы EP1. Другие сервисы для картинок не использовались. Превью EP2 не делалось.
- Графики «сигналы голода/сытости» (Sumithran) и кривая голода за сутки (Scheer) — иллюстрации по описанию в источниках, не воспроизведение их рисунков; «juice barely helped» — вывод из суммы прелоада и обеда по таблице 3 (Flood-Obbagy 2009).
- Пять фраз-советов («ладонь белка», «закрыть кухню», ужин без экрана и др.) — решения сценариста; исследования они не цитируют.

## Если продолжать

1. Пополнить баланс A6API → создать недостающие рисунки и превью (по принятому направлению ATTENTION_RU).
2. Прослушать полностью; решить, нужна ли музыка (запасной MP4 готов).
3. Выбрать название и описание, сверить с превью; только после этого публиковать.
