# Последние превью под название EP2

**How I Lost Fat Without Starving Myself** — выбранное владельцем название. Два предложения, финальный выбор владельца ещё не зафиксирован:

1. `deliver/05-fat-loss-still-eating.png` / JPG: до/после, меньшая талия и нормальный обед; STILL EATING, красная дуга по смыслу. Рекомендация агента.
2. `deliver/06-fat-loss-no-starving.png` / JPG: крупный стройный герой с обедом, NO STARVING.

Готовые PNG/JPG1280×720, меньше1МБ. Raw A6API1672×941, без фиктивного4K-апскейла. `deliver/title-match-overview.jpg` — лист сравнения, не файл для загрузки в качестве одной обложки. `review/` —320×180 варианты/обзор для проверки читаемости. Raw, prompts и JSON/SVG находятся в одноимённых папках. Герой референсируется из `../film/public/hero-cutout.png`; чужие PNG/композиции не копировались.

Код `tools/compose.py` верстает текст/векторные стрелки поверх цельной A6API-иллюстрации и экспортирует PNG/JPG. Нужен Python/Pillow, шрифты с лицензиями находятся в `branding/fonts/` корня репозитория. Из корня:

```sh
python episodes/ep2-hunger/thumbnail/tools/compose.py 05-fat-loss-still-eating 06-fat-loss-no-starving --sheet --sheet-name title-match-overview
```

Новые рисунки/позы и правки тела — только A6API через `scripts/image.ps1` или helper скилла. Проверенные последние запросы: HTTP200, ledger#4928/$0.00036 на13 октября. Цену и маршрут перед новой оплатой проверять заново. Текст/стрелка редактируются в JSON/SVG; глаза, еда и талия не должны быть закрыты подписью/указателем. Проверена мобильная читаемость, CTR не измерялся.
