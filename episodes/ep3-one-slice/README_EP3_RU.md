## EP3 — «Один кусок» (One slice)

- **Статус:** готовый черновик, не опубликован. Тема выбрана ассистентом как кандидат следующего выпуска: утверждённого плана в репозитории нет. Название, описание и сама тема не утверждены владельцем.
- **Идея:** одна осечка (кусок торта в среду в 15:40) не ломает неделю — её ломает фраза «раз уж сорвался…». Время «замораживается» в комнате с тортом; дальше эксперимент 1987 года, арифметика недели, срыв как «событие, а не вердикт», две среды, исследование о доброй фразе, три шага на ближайшие тридцать секунд (число вместо вердикта; следующий приём пищи обычный; if-then план и «не пропускай дважды»), честное предупреждение и возвращение в комнату.

### Что сделано

- Озвучка: Jonathan, `eleven_v3`, stability 0.5, нативный темп. Паузы между главами и «вдохи» заданы авторски, речь не растягивалась; тайминг слов взят из выравнивания ElevenLabs.
- Рисунки: 31 штука через A6API тремя последовательными партиями; счётчик расхода 1 544 248 → 1 554 930 единиц (≈ $0.021 по 500 000 единиц за $1). Ответ провайдера не подтверждает маршрут (`routeVerifiedByResponse: false`). Из 11 поз героя восемь взяты из набора EP1, три новые (`h-phone`, `h-point`, `h-stop`).
- Монтаж: полнокадровые иллюстрации с движением камеры, HUD-часы 3:40 PM, «замороженная» комната (ч/б, пауза) и её разморозка, сепия-флэшбэк 1980-х, графики кодом (неделя на 3500 ккал, стрелки, правило, сетка привычки), параллельные «две среды».
- Научные утверждения: пять источников и два прохода проверки (второй — независимый), оговорки и непроверенное — `notes/science-notes-ru.md`.

### Как пересобрать

```sh
# звук (нужны fluidsynth, fluid-soundfont-gm и pip install mido pedalboard soundfile numpy scipy)
python episodes/ep3-one-slice/music/compose.py && python episodes/ep3-one-slice/music/sfx.py && python episodes/ep3-one-slice/music/mix.py
# картинка и основной MP4 (кадры кэшируются; результат ../ep3-one-slice.mp4 переименован в solo-arc-ep3-one-slice.mp4)
cd episodes/ep3-one-slice/film && node doctor.mjs && npm run render
# вариант с музыкой: AAC из master-ep3-music.wav и замена звука без перекодирования видео
ffmpeg -i public/audio/master-ep3-music.wav -af apad=whole_dur=296.6666667 -t 296.6666667 -c:a aac -b:a 256k music.m4a
ffmpeg -i ../solo-arc-ep3-one-slice.mp4 -i music.m4a -map 0:v:0 -map 1:a:0 -c copy -movflags +faststart ../solo-arc-ep3-one-slice-music.mp4
```

Кадры для просмотра: `node tools/stills.mjs <папка> <секунды>[:подпись] …`; аудит текста: `node tools/timeline-check.mjs [--list]`. Кадры из итогового MP4 для проверки лежат в `film/out/ep3/final-frames/`.

### Не проверено, ограничения

- **Голос, SFX и музыка не прослушивались; ролик не просматривался целиком.** Уровни SFX и музыки выставлены по измерениям: музыка около −14 дБ к голосу в речи, самые громкие SFX — момент «Stop.» и разморозка. Требуется слуховая оценка: естественность Jonathan, теги `[resigned]`, `[flatly]`, `[warmly]`, `[softly]`, выдохи, ритм пауз, нужна ли музыка.
- Научные оговорки (подробно и с безопасными формулировками для переозвучки — `notes/science-notes-ru.md`): в ролике нет третьего условия эксперимента 1987 года (30 oz); «вкусовой тест мороженого» для работы 1987 года, число и пол её участников не проверены; «видели еду в чёрно-белом свете» у Byrne 2004 — допустимый, но не подтверждённый пересказ (шкала включает подшкалу про еду и общую); дату первого употребления what-the-hell effect проверить не удалось (позднейший обзор приписывает термин Herman и Polivy); результат Adams–Leary пограничный (p = .08), в ролике это сказано.
- Тема, название и описание не утверждены; превью EP3 не создавалось.
- В конце около 3 с чёрного кадра после ухода в чёрный; это сознательное завершение, но длину можно сократить.

### Следующие шаги

1. Прослушать ролик, выбрать вариант со звуком или без музыки.
2. Утвердить тему, название и описание; создать превью через A6API.
3. При желании усилить научную точность (эксперимент 1987 года, пересказ Byrne 2004, атрибуция термина): готовые формулировки в научных заметках; замена фраз требует новой озвучки и пересборки тайминга.
