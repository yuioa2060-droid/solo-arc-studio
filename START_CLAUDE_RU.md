## Что мы делаем

Англоязычные оригинальные иллюстрированные YouTube-ролики о похудении, фитнесе и понятных привычках. Обсуждение с владельцем — по-русски. Rendo — рабочее имя; handle не подтверждён. SOLO ARC отклонено как имя, но осталось в технических путях.

Белые/серебристые волосы, взрослый привлекательный герой, естественное тело, нейтральная серая кожа, изумрудные шорты **#0B8371**. Манга-контуры/штриховка, натуральные приглушённые цвета реквизита, чистый почти чёрный фон. Предметы/рисунки объясняют реальные слова. Jost — основной текст роликов; подписи, числа, стрелки и линии редактируются кодом. Тело не резать на куски и не деформировать по XY; сравнения показывают того же человека/объект.

База спокойная, уверенная, атмосферная. Для EP2 владелец попросил **чуть больше энергии и динамики**, разнообразный плавный монтаж без повторения расписания и композиционных ритуалов EP1. Не нагромождать текст на текст/картинку на картинку. Старую DepthStack/dimAt-схему не возвращать.

Голос: **Jonathan**, `oyxaSt75JW8l04MCJaSo`, `eleven_v3`, stability `0.5`. Естественная речь, целые окончания; marks соответствуют финальному звуку. SFX короткие и редкие, с отдыхом между whoosh; не ставить их на каждую смену Week/персонажа. Музыка EP2 — органический instrumental ambient без ударных, битов и басовой линии; мягкие нарастания, спокойные пики, читаемый голос. Самописное 8-bit/синтетическое пианино отвергнуто. Текущий финал EP2 ускоряет только intro примерно на 8% с сохранением высоты; не превращать этот конкретный retime в шаблон следующих выпусков.

Все новые картинки и любые перегенерации — **только A6API**, включая видео, превью, аву и баннер. Встроенный ImageGen/другие провайдеры не использовать. Новые важные рисунки сначала проверять малыми тестами. Утверждённое не перегенерировать без причины. Для статичного оформления нужна цельная задуманная композиция; текст/стрелку можно отдельно верстать кодом.

Научные фразы проверять по первичным работам. Персональная история иллюстрированного героя не является проверенной биографией владельца. Источники сохранять во внутреннем QA; по прямому пожеланию владельца **не добавлять research-ссылки в публичное описание**.

## Скачать и установить

```sh
git clone https://github.com/yuioa2060-droid/solo-arc-studio.git
cd solo-arc-studio
git lfs install --local
git lfs pull
npm ci
npm run browser:ensure
npm run doctor
```

Для чтения скиллов сначала без больших медиа: `GIT_LFS_SKIP_SMUDGE=1 git clone ...` в Linux/macOS. В PowerShell сначала `$env:GIT_LFS_SKIP_SMUDGE='1'`, после clone `Remove-Item Env:GIT_LFS_SKIP_SMUDGE`. Затем скачать нужное:

| Нужно | Git LFS include |
|---|---|
| Оба готовых видео | `git lfs pull --include="episodes/ep1-v11/solo-arc-ep1-v11.mp4,episodes/ep2-hunger/final/*.mp4" --exclude=""` |
| Запустить EP1 / создать следующий проект | `git lfs pull --include="episodes/ep1-v11/**,skills/solo-arc-motion/assets/**" --exclude=""` |
| Монтаж/звук/превью EP2 | `git lfs pull --include="episodes/ep2-hunger/**,branding/fonts/**" --exclude=""` |

Если вместо медиа виден `version https://git-lfs.github.com/spec/v1`, это pointer, не реальная картинка/аудио/MP4. Код и Markdown доступны без LFS. Полный checkout не включает node_modules и кэши: устанавливай по lockfile.

Нужны Node22.4+ (рекомендуется24), Python3.11+, полный FFmpeg/FFprobe и Chrome/Chromium. Remotion закреплён4.0.454. Для Python по необходимости отдельный venv и `pip install -r requirements.txt` (numpy/Pillow). Текущая повторная сборка EP2 использует FFmpeg с фильтром `alimiter` и Python stdlib, без scipy; mini-FFmpeg из Remotion не содержит нужного аудиофильтра. `lower-music-reference.py` — исторический рецепт с недоступными старшими stems, не текущая команда. Windows: при ограничении npm.ps1 использовать npm.cmd; `REMOTION_BROWSER_EXECUTABLE`, `SOLO_ARC_FFMPEG`, `SOLO_ARC_FFPROBE` задают установленные инструменты. Для Linux системные зависимости Chrome перечислены в Dockerfile.

## API и ключ последних превью

`A6API_KEY` обновлён в зашифрованном Actions Secret текущего репозитория; `ELEVENLABS_API_KEY` также в Secrets. **Обычный clone не получает значения.** Для локального/облачного Claude отдельно настроить env или игнорируемый `.env` по `.env.example`; не писать ключ в Markdown, source, коммит, общий ZIP или сообщение агенту. В другом клиенте переменные задаются его штатными настройками среды.

Рабочий A6 адрес: `https://a6.a6api.com/v1/images/edits`, модель `gpt-image-2.5`, multipart references. На13 октября подтверждён sodaro#4928/$0.00036, fallback выключен. Это историческое подтверждение, не гарантированная цена. При `pin_paused_price_changed` сначала исправить закрепление, не повторять платный запрос вслепую. [Настройка API](skills/solo-arc-motion/references/a6api-access.md).

Windows/PowerShell: `scripts/image.ps1 -PromptFile PATH -ReferenceFile PATH -OutputFile outputs/images/example.png` создаёт dry-run план. `-Send` включает один платный запрос при соответствующем задании. Linux/macOS: Node-helper `skills/solo-arc-motion/scripts/a6api-reference.mjs --help`, ключ через env. Все ключи поступают только в память процесса.

Ручной Actions workflow **Generate A6 image** подставляет Secret автоматически, получает нужный LFS-reference и по умолчанию выдаёт dry-run план; paid flag включать только для фактического задания владельца. **Generate Jonathan voice** аналогично работает с ElevenLabs. Они не запускаются автоматически при push. Actions Secrets не являются способом скачать ключ в обычный clone.

## Следующий новый ролик

```sh
node skills/solo-arc-motion/scripts/new-episode.mjs --out episodes/new-video
```

Независимая копия EP1 — только технический scaffold. Заново: английский сценарий по новой теме → режиссёрский beat/scene-map → coherent A6API PNG и их prompts/raw → Jonathan raw TTS + dry stem/marks → монтаж по словам → отдельные stems → просмотр кадров/краёв/наложений и прослушивание → master/QA. Не копировать темп/главы один к одному, не восстанавливать marks потом из сведённого MP4 и не навязывать научному объяснению выдуманную биографию.

Сохранять только актуальную версию каждого готового выпуска и реально полезные исходники. Рендер/decode не доказывают художественное принятие, отсутствие слышимых артефактов или реальную научную биографию. Принятые новые правки вносить в канон и фактический QA.
