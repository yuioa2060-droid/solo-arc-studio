# Режиссура, оригинальность и темп

## Что пользователь просит сохранить

Спокойный cinematic / solo grind arc. Это понятное объяснение с атмосферой личного усилия: персонаж — ведущий канала, а не маленькая иллюстрация рядом с неизменной таблицей. Его жест, взгляд, масштаб и временное отсутствие поддерживают мысль. Сильный результат может быть почти неподвижным несколько секунд.

Отрицательный пример из производства: речь до 1.42×, окончания обрезаны почти сразу после разметки, одинаковая учебная сетка, быстрое появление всей стрелки и открытый список вместо скрытого тизера. Эти решения технически давали видео, но меняли настроение и функцию сцен.

## Сценарий до картинок

Для каждого смыслового блока записать:

| Поле | Решение |
|---|---|
| Мысль | Что зритель должен понять или почувствовать сейчас? |
| Действие | Что действительно меняется на экране, кто действует и почему? |
| Фокус | Один главный объект; дополнительный появляется после него. |
| Ожидание | Какой вопрос пока остаётся открытым? |
| Отдача | Где обещанный ответ становится видимым и применимым? |
| Пауза | Речевая, визуальная или обе; какова её функция? |
| Рисунок | Нужен новый PNG, другая поза, предметная вставка или достаточно монтажа? |

Не заставлять каждый блок содержать все эффекты. У простого утверждения может быть только крупная фигура и тишина. Число требует ясной единицы и контекста, а не автоматического дашборда.

Для новой идеи придумать разные визуальные устройства: например, ограничение диапазона через две позы; миф и его опровержение через исчезновение лишней картинки; прогресс через заполнение одной измеримой шкалы. Выбирать по смыслу, а не автоматически начинать любой ролик с тех же четырёх карточек.

## Три разных паузы

1. **Пауза речи:** закадровый голос замолкает. Фигура может завершать вход или продолжать показ.
2. **Пауза движения:** композиция уже установилась, зритель читает форму; голос может объяснять.
3. **Пустое окно:** картинки/подписи исчезли, иногда остаются музыка или маленький номер главы. Это отделяет мысль или создаёт ожидание.

Не заполнять автоматически пустое окно новой фразой. Не считать отключение музыки единственным способом сделать паузу. Длительность зависит от смысла и реально записанной речи.

## Практические стартовые диапазоны, не универсальные константы

| Действие | Часто полезная отправная точка |
|---|---|
| Вход большой фигуры | 0.9–1.55 с, небольшой overshoot |
| Мягкое проявление | 0.45–0.70 с |
| Перекрытие разных рисунков | 0.35–0.65 с, проверить двойной контур |
| Смешивание двух поз | 0.20–0.38 с; медленнее только по смыслу |
| Прорисовка указателя | 0.65–0.95 с после подписи/фокуса |
| Разница входов строк тизера | около 0.4 с |
| Установившийся показ | отдельное окно, не остаток после анимации |

Короткая сцена не обязана иметь сокращённый резкий въезд. В ней может быть простое проявление с неподвижной фигурой. Особенно сначала показать начальное положение упражнения, затем менять позу по слову действия. Один проверенный короткий показ имел 13 кадров удержания; другой 36. Это разные постановки, а не обязательные числа для всех эпизодов.

## Речь управляет временем

Сначала готовое аудио, затем word alignment. В репозитории `voice-cues.json` содержит собственные точные слова, а исследовательская YouTubeScribe-транскрипция имеет только округлённые секунды.

Сцены привязать к конкретным словам: поднятие — к глаголу поднятия, опускание — к опусканию; диапазон повторений появляется в его речевом окне. Короткая чёрная карточка меняет текст, когда меняется произносимая мысль. Если аудио говорит другое, экранная дословная карточка недопустима.

Предварительные запасы 65 ms перед первым словом и 115 ms после последнего были полезны в этой записи, но не гарантируют сохранение фонем другого голоса. Проверять границы на слух/волне. Не растягивать скорость аудио; дать ему больше времени или сократить написанный текст и записать заново.

## Разнообразие без суеты

Чередовать функции и размеры: ведущий крупно → предмет → полный показ движения → локальное выделение → тихий акцент словами → простой график → возвращение ведущего → ясная практическая отдача. Это пример, не фиксированная схема каждого ролика.

В соседних блоках менять хотя бы один оправданный параметр: масштаб/ракурс, направление входа, тип объяснения, плотность объектов, наличие речи или порядок раскрытия. Не менять все сразу. Не добавлять случайный зум, bob и звук во все удержания.

Финал закрывает обещание вступления. Если есть варианты, явно показать выбор, а не список обязательных действий. Тизер можно собрать из тех же финальных карточек с пикселизацией, поэтому его вид и последующее раскрытие будут связанными.

## Завершение новой задачи

Оригинальный ролик завершён, когда мысль и визуальная причинность ясны, родная речь не обрезана, движения плавны, разнообразие оправдано и экспорт реально проверен. Идентичность чужому ролику больше не является критерием. Схожесть настроения оценивается отдельно от размеров файла и отсутствия DOM-ошибок.
