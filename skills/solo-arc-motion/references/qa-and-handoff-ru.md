# Проверка и передача

Сделать проверки, которые отвечают реальному изменению. Не тратить полный рендер на неизменённый эпизод ради статуса «готово». Не подменять творческую оценку техническим успехом.

## Изображения и кадр

- Идентичность/шорты/лицо/направление взгляда; оригинальность, правильные реальные предметы; без случайных рамок, неона и винтажного оформления.
- Alpha, отсутствие белой/чёрной каймы, нормальные кисти/суставы/контур, отсутствие crop важных частей.
- Проверять прямоугольные светлые полосы у краёв PNG именно в рендере: прозрачная кромка исходника не исключает артефакты фильтра и поворота. Двухпиксельный clip Item текущего EP1 убирает границу слоя; для других ассетов проверить поля и сохранение силуэта.
- Для перехода тела/позы: целые PNG, те же anchor/camera, наложения 25/50/75%, отсутствие призрачных волос/кистей/двойного силуэта.
- Текст соответствует реальной фразе, readable hold, не переполнен и не скачет из-за word emphasis; число/единица/красное зачёркивание исчезают согласованно.
- Маска следует **всему** контуру данного ассета, объясняет выбранную область; старый точечный тест не достаточен.
- Проверять начальный взгляд, meaningful objects, plan reveal, клипы вокруг сложного перехода и завершение в чёрный.

## Голос и SFX

Проверять фактический файл после всех правок и mux. Естественная скорость Jonathan, тот же тембр, нет потерянных окончаний; графика/слово/SFX согласованы; паузы имеют смысл. Голос впереди, SFX редки и тихи. Plate = tech, recap = shutter, dash после circle, без pop/bubble sound. Вуши не сопровождают автоматически каждый этап прогресса; оценивать плотность конца отдельно, оставлять слуху отдых. Музыка по заданию слышна под речью и плавно завершается; в v11 она прямо запрошена пользователем. Сохранить voice/SFX/music stems.

Инструментальные измерения: sample rate/channels/duration, отсутствие decode errors, integrated LUFS и true peak финального AAC. Ориентир −14 LUFS, TP ≤ −1 dBTP. Метр не оценивает неприятность свиста или естественность паузы: нужен слуховой просмотр. Если в среде нет честной возможности слушать, явно отметить это вместо утверждения «прослушал».

## Что именно доказывает проверка

| Проверка | Подтверждает | Не подтверждает |
|---|---|---|
| Archive CRC + SHA-256 | Чтение/целостность извлечённых байтов, дубликаты | Смысл и одобрение каждого файла |
| PNG decode + contact sheets | Изображение читается; обзор коллекции | Детальную анатомию каждой картинки |
| FFmpeg full decode | Потоки MP4 декодируются полностью | Полный художественный просмотр/слуховую оценку |
| Selected frames / short clips | Конкретные кадры/переходы | Всё остальное видео |
| Build / doctor / syntax checks | Соответствующую техническую работоспособность | Творческое принятие, медицинскую достоверность |

## Комплект передачи

Готовый MP4; редактируемый Remotion; active PNG + оригинальные raw; prompts/reference roles/request statuses; script; raw voice/words/alignment/prepared voice; SFX источники и stems; master; fonts/license; references; version feedback; QA с точными выполненными проверками; скилл; краткий первый prompt следующего чата; manifest с источниками и hash.

Не включать node_modules, browser cache, промежуточные гигантские render-cache и секреты. Ключи отдельным credentials/env каналом, не печатать и не записывать в Markdown. Передавать текущий рабочий комплект. Прошлые MP4, архивные сборки и переписку в этот репозиторий не включать.

Новые решения записать так: дата → точная фраза/кадр → прежняя проблема → принятое состояние → файл/код → статус approved/candidate/history → отменённые правила → проверка. Не смешивать собственное предположение помощника с прямым принятием пользователя.
