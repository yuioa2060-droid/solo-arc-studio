## 10. A6API и экономия

Рабочий адрес: https://a6.a6api.com/v1; модель gpt-image-2.5; references — multipart POST /images/edits. Это внешний прокси-провайдер. Один image field для одного референса, image[] для нескольких, model/prompt/n/size. Node-helper допускает только HTTPS-хосты `api.a6api.com` и `a6.a6api.com`; BASE_URL задаётся окружением. PowerShell-адаптер использует подтверждённый `a6.a6api.com` и сверяет текущий pricing/ledger.

13 октября #5752 вернул `pin_paused_price_changed`: продавец повысил цену и закрепление приостановилось. Владелец явно поручил сменить маршрут на ближайший подходящий. Снято это закрепление и выбран совместимый#4928 той же модели, без широкого fallback; успешные новые картинки подтверждены. При похожей ошибке сначала проверить закрепление/актуальную цену; не трактовать HTTP402 автоматически как отсутствие баланса. После timeout/ошибки сначала сверить ledger, затем решать, нужен ли новый запрос. Не перебирать поставщиков после рабочего результата.

14 октября владелец подтвердил: актуальный ключ — тот, которым генерировали последние превью. **`A6API_KEY` обновлён в зашифрованном Actions Secret репозитория `yuioa2060-droid/solo-arc-studio`.** Значений ключа нет в source/Markdown/Git/общем ZIP. Clone не получает секреты: локальному Claude/Hoplite задать отдельное runtime окружение или игнорируемый `.env`. Ручной workflow Generate A6 image использует Secret автоматически. Платный флаг по умолчанию false; packaging и обычный push не запускают генерации.

Сначала один необходимый тест с референсом, посмотреть, потом масштабировать. Кэшировать prompt/reference hashes, не регенерировать принятое без причины. Журнал каждой попытки: начало/конец, model/channel, ожидаемая цена, HTTP/результат, факт оплаты. HTTP timeout не доказывает $0. Биллинг смотреть /api/log/token, quantity/quota/market_price_micros. Количество сохранённых картинок не равно числу оплаченных запросов. Новый helper не выбирает поставщика автоматически: strict pin проверяется в аккаунте; audit не выдаёт декларируемый route за доказанный ответом.

Эта передача не запускает платную генерацию/TTS. Для Claude без инструментов подготовить файлы/промпты и назвать ограничение; не притворяться выполненным API/рендером. Для Claude Code использовать ключ через env/Actions; публичный репозиторий не является secret-хранилищем.



Node-helper: `scripts/a6api-reference.mjs --help` внутри скилла. По умолчанию offline dry-run; --send выполняет один платный запрос без автоматического повтора/смены маршрута. Перед --send нужны текущие account pin и expected price. Declared route/price не выдаются за подтверждённый фактический канал/оплату. Ключ из A6API_KEY; при локальной работе `node --env-file=.env ...` читает игнорируемый файл из корня репозитория.

Windows / pwsh: корневой `scripts/image.ps1 -PromptFile PATH -ReferenceFile PATH -OutputFile outputs/images/new.png [-AdditionalReferences PATHS] [-Size 1536x864] [-Send]`. Без -Send — план; ключ берётся из env или игнорируемого корневого `.env`. Helper не перезаписывает готовые картинки, проверяет native bytes/формат, сохраняет sanitized audit, pricing и ledger. Не печатать raw error/response с возможными credentials. Если ledger вернул несколько новых строк, не объявлять стоимость одной картинки однозначно установленной.
