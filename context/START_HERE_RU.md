# SOLO ARC: актуальный контекст

Последний готовый ролик — EP1 v11. Применены пожелания владельца: реже whoosh в конце, присланная музыка заметно слышнее, чистый фон без шума по краям.

1. Прочитать `../AGENTS.md` и `../skills/solo-arc-motion/SKILL.md`.
2. Канон: `../skills/solo-arc-motion/references/current-rules-ru.md`.
3. Для производства: `episode-workflow-ru.md` в том же references.
4. Рабочий пример: `../episodes/ep1-v11/README_V11_RU.md`, `film/`, `voice/`, `prompts/`, `raw/`.

Прямое новое задание владельца выше зафиксированных правил. Старые сборки, MP4 предыдущих версий и архивная переписка исключены. Новый предложенный сценарий, его название/hook, перевод, voice text и постановочный план также не включены.

Канал: похудение/фитнес, спокойный solo-grind, английский Jonathan, беловолосый герой с изумрудными шортами, осмысленные манга-объекты и монтаж по словам. Действующие подробные требования уже сведены в current-rules; заново восстанавливать их из архивов не требуется.

Mort1d находится в `../skills/solo-arc-motion/engines/html-motion/`: код, приёмы анимации, инструменты, шрифты и лицензия. Его общие рекламные defaults не меняют правила канала.

Ключи ElevenLabs/A6API сохранены в зашифрованных GitHub Secrets; локальный запуск использует окружение или игнорируемый `.env`. Команды — в `../README.md`. Новый выпуск начинать с темы/сценария по новому заданию, не подставлять старые word timings под новую речь.
