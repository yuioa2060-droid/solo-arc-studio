# Превью «до/после»: внимание, красная стрелка и крупнее талия

**12.10.2026.** Владелец остановил работу над баннером и попросил подумать, как сильнее привлечь внимание к сравнению «до/после», предложив красную стрелку. Подготовлены три новые **цельные правки через A6API**. Текущий PNG не заменён, новый вариант ещё не выбран.

![Текущее превью и три идеи](attention/comparison.jpg)

**Последнее уточнение:** владелец попросил показать вариант **без перегородки и с изогнутой стрелкой**. [Готовая цельная правка A6API](attention/04-curved-no-divider.png). Линия удалена, стрелка и надпись сохранены. Ещё один одиночный запрос, $0.001404 по журналу. Это дополнительный вариант для оценки; основное превью не заменено.

## Выбор и смысл

| Вариант | Что меняется | Редакционная оценка | Полный PNG |
|---|---|---|---|
| A | Текущее превью без стрелки. | Спокойная исходная версия для сравнения. | [1664 × 936](thumbnail.png) |
| B | Одна крупная прямая красная стрелка в центре под `12 WEEKS`. | Заметная и простая, но добавляет довольно грубый акцент. | [1664 × 936](attention/01-straight-arrow.png) |
| **C** | **Изогнутая красная стрелка справа указывает на край стройной талии.** | **Мой первый выбор для пробы со стрелкой:** выделяет сам результат, оставляет середину свободной. | [1664 × 936](attention/02-curved-arrow.png) |
| **D** | **Крупнее одинаковый кроп талии, без стрелки.** | **Мой второй выбор:** усилить саму разницу форм, сохранив спокойный стиль. | [1664 × 936](attention/03-waist-closeup.png) |

[Сравнение в размере 320 × 180 для каждого варианта](attention/small-comparison.jpg). C и D рекомендованы агентом, не утверждены владельцем. Это дизайнерские гипотезы: просмотры или CTR этих вариантов не измерялись. Добавление стрелки само по себе не гарантирует охват.

Стрелка должна быть одна, отчётливо красная, с понятной целью; не закрывать надпись или контур живота. Не раскрашивать красным само тело, не добавлять круги/несколько указателей. В первых новых вариантах сохраняем изумрудные шорты, мягкий локальный белый свет, профиль и смысл «обычный мягкий живот → здоровая стройность без пресса». У D кроп увеличен одновременно для обеих фигур. `12 WEEKS` остаётся подписью иллюстрированного прогресса, не обещанием результата каждому.

## Генерация и источник

Каждый новый вариант — **полный ответ A6API**, включая стрелку, рисунок, свет и надпись. Стрелки не дорисованы программно, тела не собраны из отдельных частей. При экспорте выполнены только равномерное уменьшение/минимальный кроп до 16:9 и создание листов сравнения. Надписи A/B/C/D принадлежат листам сравнения, не самим превью.

Модель — `gpt-image-2.5`, endpoint — `https://a6.a6api.com/v1/images/edits`. Четыре оплаченных одиночных запроса, **$0.006036 суммарно по журналу A6API**: три начальные идеи и исправление цели стрелки C. Первоначальная дуга указывала на руку; этот PNG сохранён только как необходимый вход следующей правки, а не как четвёртый вариант для публикации.

Запрошен размер 1536 × 864; фактически получены **1672 × 941**. Итоговые PNG — **1664 × 936**, без увеличения рисунков. 4K не заявляется. [Промпты и фактические оплаты](assets/attention-generation.json), [проверки экспорта](attention/quality-check.json).

Исходные ответы: [B](assets/attention-straight.png), [C](assets/attention-curved.png), [D](assets/attention-closeup.png). [Вход исправления C](assets/attention-curved-input.png) нужен для воспроизведения цепочки. Его исходный запрос — [02-curved-arrow.txt](prompts/02-curved-arrow.txt), исправление — [02-curved-arrow-refine.txt](prompts/02-curved-arrow-refine.txt). Остальные: [01-straight-arrow.txt](prompts/01-straight-arrow.txt), [03-waist-closeup.txt](prompts/03-waist-closeup.txt).

## Продолжение работы

Выбрать направление C или D по следующему сообщению владельца. При доступном A/B-тесте разумно сравнить A/C/D с одним названием видео. Текущий файл `thumbnail.png`, название, MP4 и поля YouTube не менялись.

На Windows с ключом в `A6API_KEY` доступен [адаптер](../../skills/solo-arc-motion/scripts/a6api-windows.ps1): без `-Send` выполняет только dry run; `-Send` делает один платный запрос. Он не меняет настройки маршрутизации аккаунта, не отключает TLS и не делает автоматических повторов. Цена/маршрут на эту дату не гарантируются для следующих запросов; сверять журнал после каждого. Секретов в репозитории нет. Для других сред остаётся Node-helper скилла.

~~~powershell
./skills/solo-arc-motion/scripts/a6api-windows.ps1 -PromptFile ./branding/thumbnails/prompts/01-straight-arrow.txt -ReferenceFile ./branding/thumbnails/thumbnail.png -OutputFile ./new-thumbnail.png -Size 1536x864
~~~

Экспорт уже сохранённых ответов, без запросов к модели:

~~~sh
node branding/thumbnails/build-attention.mjs --sharp-module /absolute/path/to/node_modules/sharp
~~~

Все четыре исходных ответа и три конечных экспорта просмотрены. Проверены читаемость `12 WEEKS`, отсутствие пресса, положение красного акцента, чёрный фон, одинаковая направленность профилей и небольшие превью. Это локальная визуальная проверка; окончательный выбор и реальная реакция зрителей ещё впереди.
