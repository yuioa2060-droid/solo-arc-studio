# Banner fonts

These files support Rendo lettering. The three current banner directions use Anton, Bebas Neue and Bangers; all listed families use the SIL Open Font License 1.1, included beside each font.

| Font | Official source | Local license |
|---|---|---|
| Anton Regular | [Google Fonts file](https://raw.githubusercontent.com/google/fonts/main/ofl/anton/Anton-Regular.ttf) | [Anton-OFL.txt](Anton-OFL.txt) |
| Bebas Neue Regular | [Google Fonts file](https://raw.githubusercontent.com/google/fonts/main/ofl/bebasneue/BebasNeue-Regular.ttf) | [BebasNeue-OFL.txt](BebasNeue-OFL.txt) |
| Bangers Regular | [Google Fonts file](https://raw.githubusercontent.com/google/fonts/main/ofl/bangers/Bangers-Regular.ttf) | [Bangers-OFL.txt](Bangers-OFL.txt) |
| DM Serif Display Regular | [Google Fonts file](https://raw.githubusercontent.com/google/fonts/main/ofl/dmserifdisplay/DMSerifDisplay-Regular.ttf) | [DMSerifDisplay-OFL.txt](DMSerifDisplay-OFL.txt) |
| Caveat variable font | [Google Fonts file](https://raw.githubusercontent.com/google/fonts/main/ofl/caveat/Caveat%5Bwght%5D.ttf) | [Caveat-OFL.txt](Caveat-OFL.txt) |

Anton, Bebas Neue and Bangers downloaded on 2026-10-12. DM Serif Display and Caveat were downloaded on 2026-10-11 and remain supporting font resources. Montserrat Black Italic and its license are bundled in `skills/solo-arc-motion/engines/html-motion/assets/template/assets/fonts/`. Jost is in `episodes/ep1-v11/film/public/fonts/` and remains the video font.
