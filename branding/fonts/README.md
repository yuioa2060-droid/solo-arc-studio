# Banner fonts

These files support the current Rendo lettering options. Both families use the SIL Open Font License 1.1; license texts are included beside the fonts.

| Font | Official source | Local license |
|---|---|---|
| DM Serif Display Regular | [Google Fonts file](https://raw.githubusercontent.com/google/fonts/main/ofl/dmserifdisplay/DMSerifDisplay-Regular.ttf) | [DMSerifDisplay-OFL.txt](DMSerifDisplay-OFL.txt) |
| Caveat variable font | [Google Fonts file](https://raw.githubusercontent.com/google/fonts/main/ofl/caveat/Caveat%5Bwght%5D.ttf) | [Caveat-OFL.txt](Caveat-OFL.txt) |

Downloaded on 2026-10-11. The builder uses Caveat Bold. Montserrat Black Italic and its license are already bundled in `skills/solo-arc-motion/engines/html-motion/assets/template/assets/fonts/`. Jost is already in `episodes/ep1-v11/film/public/fonts/` and remains the video font.
